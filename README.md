<h2 align="center">🛠️ &nbsp;How I work — audit → design → build → measure</h2>

<div align="center">

| `01 · AUDIT` | `02 · DESIGN` | `03 · BUILD` | `04 · MEASURE` |
| :--: | :--: | :--: | :--: |
| 🔍 | 🎨 | 🧱 | 📐 |
| Read the current thing honestly — payload, contrast, tap targets, Lighthouse, axe, real phone. Write it down. No vibes. | Tokens first: colour, type, spacing, motion. Figma → system, not screens. 44px min, focus visible, reduced-motion variant. | Semantic HTML, accessible components, motion that respects `prefers-reduced-motion`, WebP + lazy, budgets enforced in build. | Lighthouse + axe + a real mid-range phone on throttled 4G. Ship the number, not the vibe. If it regresses, it ships again. |

</div>

<details>
<summary><b>🧾 &nbsp;My non-negotiables — what I won't compromise</b></summary>
<br/>

- ♿ **Accessibility isn't a phase.** Semantics and contrast come before the pretty pass. Keyboard, screen reader, focus, reduced-motion — all first-class.
- 📱 **Mobile is the real build.** Desktop is the wide version of it, not the other way round. If it doesn't work on a ₹15k Android, it doesn't work.
- ⚖️ **Budgets, not guesses.** Every page gets a weight limit before a single asset lands. Fail the build if crossed.
- 🎚️ **Motion with a mute switch.** `prefers-reduced-motion` is honoured everywhere. No motion that makes people dizzy.
- 🧮 **Numbers or it didn't happen.** Case studies quote measured before/after, including the ugly ones. No fake percentages.
- 🔒 **No secrets in repo.** No `.env`, no `node_modules`, no build artifacts. Honest `.gitignore`.
- 📝 **Docs or it doesn't exist.** Every component gets usage, props, a11y notes.

</details>
